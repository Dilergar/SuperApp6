# Орг. структура — веб (канвас, мастер, профиль)

> Витрина оргструктуры: полноэкранный канвас React Flow над справочниками (координаты не хранятся), мастер первичной сборки, «Вне структуры», мобильное дерево, «Место в структуре» в профиле. Модель, вывод вертикали, права и API — [org_structure.md](org_structure.md).

Код: `apps/web/src/app/workspaces/[id]/members/org/` — `OrgStructure.tsx` (вход, тулбар, состояние витрины), `OrgCanvas.tsx` (React Flow поверх общего `FlowCanvas`, жесты), `org-layout.ts` (детерминированная раскладка), `OrgNode.tsx` (узел-должность, рамка отдела), `OrgSidePanel.tsx` (панель должности/отдела/объекта, держатели, заместители), `OrgUnassigned.tsx`, `OrgWizard.tsx`, `OrgCreateModals.tsx`, `OrgTree.tsx` (мобильное дерево), `org-lib.ts`, `org.css`; общее для канвасов — `apps/web/src/components/canvas/` (`FlowCanvas.tsx`, `canvas.css`, `tone.ts`), фетчеры — `apps/web/src/lib/org-api.ts`, ключи — `apps/web/src/lib/queries.ts` (`orgChartKey`…), профиль — `apps/web/src/app/workspaces/[id]/members/[userId]/page.tsx`.

## Канвас и разделы

`/workspaces/[id]/members/org` — полноэкранный канвас (React Flow, `next/dynamic ssr:false`; общее с Процессами — `apps/web/src/components/canvas/`). Слой — общий класс **`.canvas-layer`** (globals.css): `left: var(--svc-w)` и `z-index: 30` НИЖЕ сайдбара (40) и топбара (50). `inset: 0` в полноэкранном слое запрещён — он раскрывается в `left: 0`, накрывает второй уровень навигации, отдаёт полотну жесты в полосе сайдбара и оставляет фокус на невидимых ссылках. Узел канваса: узел = должность (`<Glyph/>`, стек `PersonAvatar`, чип отдела, маркер головы), отдел = рамка-группа (≤2 уровней), сплошная — подчинение, пунктир — замещение; переключатель видов; фильтр «Объект» (`?branchId=`; вершина — руководитель объекта, пустые должности пунктиром); «моя ветка» по умолчанию, управляющим — вся; `?focus=` из ростера/профиля/поиска; перетаскивание карточки в рамку = смена отдела, провод = переопределение (400/403 → откат + `toastError`); панель справа открывается ФАКТАМИ (отдел, «Подчиняется: …», держатели, заместители), правка и удаление — под кнопкой «Изменить»; клавиатура: Tab по узлам, Enter/Пробел открывает панель, Escape закрывает и возвращает фокус на узел (`aria-label` узла — «Должность «…», держателей: N»); «Вне структуры»; мастер «Соберём структуру». **Мобильный фолбэк** (< 768) — дерево-список из тех же данных без перетаскивания. Профиль `/members/[userId]`: «Место в структуре» (руководитель `PersonChip`, «замещает до …», подпись `owner_fallback`, команда стеком, цепочка, «также»).

## Раскладка (`org-layout.ts`)

Лес по серверному `superiorPositionId` (корни — `roots`; при фильтре объекта первым — руководитель объекта), сортировка соседей: ранг отдела → `sortOrder` → имя (кластеры отделов сплошные), ширины поддеревьев post-order, узел центрируется над детьми; фиксированный размер узла 240×116, уровни через 120px. Рамка отдела = bbox своих должностей (+ вложенных рамок) с подушкой и заголовком; членство — по `departmentId` должности (голова вне отдела остаётся снаружи). **Рамка не рисуется**, если в её bbox попал чужой узел или она пересекает соседнюю — иначе она врёт (чип отдела на узле остаётся всегда). Пунктир замещения идёт через невидимые боковые порты (`sl/sr/tl/tr`), чтобы не резать узлы по вертикали; провод человек тянет только из нижнего порта в верхний. Цикл в данных (стоп-кран сервера) не вешает раскладку: недостижимые узлы становятся корнями.

## Ловушки

- Общий канвас: css после `@xyflow/react/dist/style.css`; группы v12 — родитель раньше детей, явные `width/height`; рамки с отрицательным `zIndex` (под рёбрами), `elevateNodesOnSelect` выключен; `extent:'parent'` НЕ ставится — он не дал бы вытащить карточку в другую рамку. Скрытая панель не рисует рёбра.
- Жесты без оптимистичных правок: на время запроса узел стоит там, куда его бросили; ответ сервера (успех или 400/403 + `toastError`) бампает `resetTick` → узлы возвращаются на места раскладки, а свежий снимок перерисовывает схему.
- Мастер: `POST /org/setup` вершину к объектам не привязывает — клиент сам подставляет вершину головой ОСНОВНОГО объекта (шаг 2, синтетический `__top__` для новой должности) и после setup доводит головы «= вершина» отдельными PATCH; без этого «во главе» ничего не подчинялось бы.
- `entities.ts` кэширует `/staff` модульной Map для пикеров — канвасу свой React Query (`orgChartKey`), инвалидация после мутаций — `orgRootKey` + `invalidateEntities`.
- Детерминизм раскладки: координаты не хранятся, сортировка на каждом уровне явная — иначе схема прыгает при каждом обновлении.
- Легаси `?tab=deadlines|invites|branches|positions|departments` — клиентский редирект на разделы (`useLegacyMembersTabRedirect`), не удаление: уведомления КЭДО и плитка Главной живут долго.

## Проверка

Браузер (фронтовая видимая вкладка, консоль чистая): мастер на несобранной организации · рамки ≤2 уровней · вакансия → «Нанять» · карточка в другой отдел · провод-переопределение · откат 400 с `toastError` · «моя ветка» у рядового / вся у управляющего · фильтр объекта · замещение пунктиром · Процессы пиксель-в-пиксель · `$RC(` → 0 · 375px дерево без горизонтальной прокрутки.
