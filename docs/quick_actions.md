# core/quick-actions — быстрые действия чата

> Реестр кнопок ＋-меню композера и меню сообщения (вместо слэш-команд — кнопки, как у гигантов: Slack Shortcuts / Teams message-actions). Новый сервис добавляет кнопку одной регистрацией.

## Модель

Сервис регистрирует действие `{ключ, ярлык, иконка, scope: composer|message, право}`; меню строятся из реестра по правам + типу чата. Форма = модалка, результат = Rich Card в чате.

## API

`GET /quick-actions?chatId=&scope=composer|message`.

## Зарегистрированные действия

Создать задачу (из сообщения → в описание) · Событие календаря · Напомнить = отложенное сообщение (`ScheduledMessage` + джоб core/jobs) · finance.add-expense · Диск.

Carve-out: движок читает таблицу `chat` напрямую (допустимо для монолита, см. [module_graph.md](module_graph.md)).

## Проверка

`verify-quickactions.cjs` (реестр+права+scope; цитаты; отложенные — джоб реально отправил).
