# Конвенции веба (apps/web)

> Правила для любого UI-кода. Перед созданием/редактированием ЛЮБОГО компонента обязательно читать `/DESIGN.md` (действующая система — Organic Bento warm matte). Здесь — механика и несущие запреты.

## Каркас и навигация

- **`AppShell`** (`components/shell/`) — ЕДИНЫЙ каркас приложения: глобальный сайдбар 264px с деревом (2 уровня) + топбар с переключателем «Личное / Организация». Новый сервис = +1 строка в реестре `lib/app-nav.ts`; рейл 60px/шторка/cookie/Ctrl+B — из коробки. Своих навбаров страницы НЕ рисуют.
- Каркас выводит контекст «Личное / Организация» ИЗ ПУТИ (`/workspaces/[id]/...`) → **адрес обязан нести организацию** (рабочая заявка/документ живут внутри `/workspaces/[id]/…`; личный маршрут сам переадресует рабочую сущность внутрь организации).
- Верхние иконки топбара (стопка решений, колокольчик, упоминания) — СКВОЗНЫЕ (без скоупа); витрины ВНУТРИ контекста скоуплены. У выборки «что ждёт меня» ТРИ состояния скоупа: `workspaceId` · `scope=personal` · без параметров (сквозной).

## Примитивы

- **Только кит `components/ui/`** (Button, Input, Select, Modal, Chip, Card, TickBar, Toggle, Menu, Tabs, Pagination, DatePicker, Dropzone, Alert, EmptyState…). Витрина состояний — `/dev/ui` (dev-only). Свои примитивы страницам запрещены; каталог — `/DESIGN.md`.
- **Нативные `confirm()`/`alert()` ЗАПРЕЩЕНЫ** (и линтером): браузерная галочка «блокировать диалоги» заставляет их молча возвращать false — кнопка удаления перестаёт работать без признаков. Вместо них `useConfirm()` (`components/ui/useConfirm.tsx`) и `toastError()` (`lib/toast.tsx`).
- Текст ошибки API — общий `apiErrorMessage` из `lib/api.ts`; свой разбор `error.response.data…` на странице не писать.
- **Выгрузка файла с JWT-ручки — только БАЙТАМИ** (`apiGetRaw` → blob): голая `<a href>` на защищённую ручку = всегда 401 (прецеденты: протокол подписания, экспортный ZIP, кадровые выгрузки).
- Поля — только из кита с `label`/`aria-label` (кит сам связывает `htmlFor`+`id`); голый `<input className="ui-input">` с несвязанным `<label>` оставляет поле без имени.
- Закрытие оверлеев — единый `CloseChip` (самодельный × запрещён). Модалка кита: `role="dialog"` + Esc + ловушка фокуса + возврат фокуса.

## Человек и выбор сущностей

- **Человек в UI = ТОЛЬКО `PersonChip`/`PersonAvatar`** (5 форм-факторов XS/S/M/L/XL), не голый текст — несущее продуктовое правило (видимость платных скинов карточек). Пикеры — карта M; инлайн-упоминание — S; грид Окружения — L→XL.
- **Выбор человека/группы/отдела/должности/филиала — единый `EntitySelector`** (`components/EntitySelector.tsx` + реестр `lib/entities.ts`). Тип `user` — контекстный: с `context={{workspaceId}}` лоадер отдаёт РОСТЕР организации (вся команда, ВКЛЮЧАЯ самого себя; Подрядчик исключён), без — личное окружение. Правило: **пикер не предлагает того, что сервер отвергнет**.
- Значок, выбранный человеком, — данные: рисует `<Glyph/>`/`<EmojiIcon/>`, выбирает `<GlyphField/>` (три каталога). Значок из API — ключ реестра иконок (`icon: 'robot'`); незнакомый ключ рисуется запасной иконкой. Свои поля «Значок» и разборы «имя иконки или эмодзи?» запрещены.
- Иконки — Phosphor Light через `<Icon/>`; прямой импорт из пакета запрещён.

## React Query

- **Ключ запроса — в `lib/queries.ts`, не литералом на странице** (литерал в одном месте + общий ключ в другом = молчаливый рассинхрон кэшей).
- **Один ключ = ОДНА форма кэша**: `useQuery` и `useInfiniteQuery` на общем ключе несовместимы (плоская страница чужого useQuery роняет ленту на «reading 'length'» при клиентском переходе). Общая лента объявляется один раз через `infiniteQueryOptions` рядом с ключом; потребитель первой страницы читает `pages[0]`.
- Глобально: `refetchOnWindowFocus: false`, retry только 5xx. Мутации инвалидируют общий префикс ключа.

## Auth и сессия

- `useAuthStore` (`lib/stores/auth.ts`) — единственный источник правды, токены в localStorage только через store; защищённые страницы — `useRequireAuth`.
- `hydrate()` сносит токены ТОЛЬКО на 401/403 (500/таймаут/оффлайн не выкидывают на логин).
- Выход/вход — `lib/session-reset.ts` (`resetSessionCaches`): чистит кэш React Query и модульные кэши (скины, пикеры) — иначе следующий вошедший видит кэш предыдущего.
- ОДИН socket.io-коннект на вкладку (синглтон с подписчиками); heartbeat паузится на скрытой вкладке.

## Маршруты и границы

- **Новый сервис = +1 файл `<сервис>/loading.tsx`** (реэкспорт `components/shell/RouteLoading`). В корне `app/` держать НЕЛЬЗЯ — корневой loading.tsx вешает 404 на вечный спиннер (проверено). `not-found.tsx` и `error.tsx` — в корне, на русском, внутри каркаса.
- ⚠️ **Suspense-граница + >~12.8 КБ серверной разметки под ней = вечный спиннер в невидимой вкладке** (содержимое едет отдельным чанком с инструкцией `$RC` через rAF, а в скрытой вкладке кадров нет; сервер отдал 200, консоль чистая). Авторизация клиентская — серверу рисовать нечего: ранний выход по `mounted` до гидратации (после ВСЕХ хуков). Скрининг: `curl -s <url> | grep -c '$RC('` → 0 = хорошо.
- Тяжёлые страницы (канвас Процессов, комната звонка, WOPI-редактор, оверлей звонка) — `next/dynamic ssr:false`.

## Длинные ленты

- Виртуализация — **react-virtuoso** (модель Telegram: в DOM только видимые строки). Правила из ленты мессенджера (переиспользовать, не изобретать): `firstItemIndex` для догрузки вверх без прыжка (индекс и данные — одним коммитом); `startReached` на монтировании ЛОЖНЫЙ (до первых замеров «верх достигнут» сразу — нужен засов); индексы асимметричны (`itemContent`/`startReached` — абсолютный, `scrollToIndex`/`initialTopMostItemIndex` — индекс в массиве); отступы — на строке, не на контейнере (движок меряет offsetHeight); `getElementById` для перехода не годится (половина истории не смонтирована).

## Производительность и dev

- dev идёт на **Turbopack** (`next dev --turbopack`); запасной путь — `pnpm --filter ./apps/web dev:webpack`.
- ⚠️ CSS-импорты пакетов из чистого `.ts`-модуля Turbopack в сборку НЕ кладёт — переносить в `.tsx` компонента.
- ⚠️ **Mantine запинен на ^8.3.11** (прямая зависимость apps/web) — НЕ поднимать до 9, пока Next не на react 19.2+ (Mantine 9 зовёт `useEffectEvent`, которого нет в вендоренном react App Router).
- Lottie — через `next/dynamic` + IntersectionObserver-гейт.
- Мобильный веб обязан работать: 375px без горизонтального скролла; сетки модалок — `auto-fit`, не жёсткие столбцы.

## Линтер веба

`apps/web/eslint.config.mjs` (flat, только стражи границы): `api.*` вне адаптера, `.data.data`, нативные `confirm`/`alert` — все `error`; `pnpm lint` веба = `eslint src`, шаг в CI. Правила Next/react-hooks здесь не живут (их дом `next lint`).
