# core/templates — заполнение шаблонов документов

> Тонкая подсистема БЕЗ своих таблиц: синтаксис + компилятор + форматтеры — НАШИ и вечные; **драйвер рендера — СВОЙ и сменный** (docx + builder). Владелец данных отдаёт группу полей регистрацией; заполнение — сервисными методами.

## Синтаксис (формат-агностичный, от драйвера не зависит)

`{Organization.Bin}` · форматтеры цепочкой `{Field|date:long}` · повтор строки таблицы `{#Rows}…{/Rows}` + `{No}`. Шаблоны клиентов написаны на этом синтаксисе — драйвер и синтаксис не трогать (упрёмся — подключается запасной драйвер без переделки шаблонов).

**Имена тегов — английские идентификаторы** (модель Salesforce): API-имя поля одно на все языки бумаги, а подпись к нему в панели «Что подставить» даёт каталог. Номер элемента повтора — `{No}`, а не `{#}`: с решётки начинается открытие повтора.

## Драйвер docx (`docx-render.driver.ts`, fflate)

Текст-узлы `<w:t>` собираются в «виртуальный текст» с картой смещений — тег, РАЗОРВАННЫЙ Word'ом на прогоны, находится и собирается; между абзацами/`<w:br/>` — сентинел (через него тег честно НЕ собирается, `tag_broken_by_break`); замена — хирургия только внутри текст-узлов (значение наследует форматирование первого узла); многострочные значения — настоящие `<w:br/>`; повтор = клонирование `<w:tr>`.

**Ошибки только громкие**: `TemplateCompileError` (битые теги, парность — ПОЛНЫМ списком) и `TemplateDataError` (список недостающих полей). Слово «undefined» в документе невозможно by construction.

**Замечание слов не хранит.** `TemplateIssueDto` несёт `messageKey` (ключ ветки `errors.templates.*`) + `params`, а не фразу: драйвер и компилятор работают и в джобе, где языка запроса нет. Слово подбирает ОДНА точка на выходе — `templateIssueText(i18n, issue)` (`TemplateRenderService.issueText` / `.withText`), там, где язык известен. Так говорят ВСЕ замечания — и docx-компилятора, и блочного конструктора, и форматтеров (`TemplateFormatError` несёт `messageKey` + `params`). `Error.message` — машинный, для лога.

## Драйвер builder (`builder-render.driver.ts` + `PdfRenderService`)

Блочные шаблоны конструктора (формат блоков — СВОЙ в shared: `types/doc-builder.ts` + рекурсивный Zod): блоки → печатный HTML А4 (PT Serif — казахский алфавит; шрифты `infra/pdf-fonts/` замонтированы в контейнер И подключены в вебе — превью и PDF одним шрифтом; ГОСТ-подобные поля; missing по контракту честности: strict → `TemplateDataError`, мягко → видимая метка ‹…›) → **Gotenberg** (профиль pdf, :3030; печатает Chromium — совпадение с браузерным превью 1:1; колонтитул «стр. N из M» — нативный footer, НЕ preferCssPageSize). `GOTENBERG_URL` пусто → рендер выключен честно.

**Чип данных в конструкторе атомарен** (`path` в формате docx-тегов «Organization.Bin») — реестр полей и форматтеры ОБЩИЕ для обоих видов шаблонов; сломать тег изнутри невозможно. Публикация builder-шаблона валидируется `checkBuilderDoc`: чипы сверяются против реестра полей И объявленной формы, отказ — 400 ПОЛНЫМ списком; «пустой шаблон» = нет ни одного блока С СОДЕРЖИМЫМ, а не `blocks.length === 0`.

## Форматтеры (`template-formatters.ts`)

`date`/`date:long` (строка «2026-09-01» разбирается КАЛЕНДАРНО, без часовых поясов; моменты — через APP_TIMEZONE) · `words` (тенге/тиын до триллионов) / `words:number` · `number`.

**Язык у форматтеров — язык БЛАНКА** (`TemplatePrint`, приезжает параметром): «прописью» и месяц берутся у языка, а разделитель разрядов и порядок частей даты — у РЕГИОНА (`01.09.2026` и в английском бланке). Числительные каждого языка — отдельный файл-словарь (`words/ru.ts`, `kk.ts`, `en.ts`): это грамматика, а не подписи экрана, поэтому `ru`/`kk` стоят постоянными исключениями стража кириллицы. Булево печатается словом бланка (`templates.print.yes|no`).

## Реестр групп полей

```ts
TemplateFieldRegistry.register({ key, tagPrefix, fields: [{ key: 'Bin', id: 'bin' }], resolve(ctx) })
// onModuleInit владельца данных
```

**Реестр слов не хранит.** `key`/`tagPrefix` — имена ТЕГА (`{Organization.Bin}`), `id` — то же имя в camelCase, из которого собирается ключ каталога по соглашению:

```
templates.fields.<группа>.label            // «Организация» / «Ұйым» / «Organization»
templates.fields.<группа>.<id>.label       // подпись поля в панели
templates.fields.<группа>.<id>.example     // необязателен (спрашивается через has)
```

Неймспейс `templates` — СЕРВЕРНЫЙ: `list()` рендерит подписи в языке запроса, и на провод уезжают уже слова (`TemplateFieldGroupDto.label`) — ни один layout веба этот каталог в браузер не кладёт. Там же живут слова, которые ПЕЧАТАЮТСЯ в бумаге (`templates.print.*`: «М.П.», «№ … от …», «БИН/БИК/ИИК» шапки, «серия/№/от» свидетельства НДС, «стр. N из M» колонтитула, «Да/Нет») — их язык это язык БЛАНКА, а не зрителя.
Слова к именам форматтеров — `documents.formatter.<имя>.label|hint` (`TEMPLATE_FORMATTERS` в shared — просто список имён).

**Значение группы печатается ВНУТРИ бумаги**, поэтому слово в нём («ЖШС», «Перевод», «серия … от …», основание подписи) берётся в языке БЛАНКА: он приезжает в `TemplateFieldContext.language`, а собирает строку `documentWords(i18n, language)`.

Группы: `Organization` (Workspaces: реквизиты + основной счёт + директор; тумблеры видимости реквизитов здесь НЕ действуют осознанно — право формирования проверяет потребитель) · `Employee` (Staff: анкета + должность/отдел/объект + **`Manager`, `ManagerPosition`, `BranchHead`, `BranchHeadPosition`** — по факту через `managerOf`/держателей головы объекта, вершина → владелец; ФИО = Фамилия Имя Отчество; приоритет должности — legalPositionId из трудовой карточки, затем основное место) · `Document` · `Counterparty` · `Contract`/`Action`/`Signer` (КЭДО). Контекст резолва несёт `templateId`/`hrActionId`.

**Контракт честности резолвера**: незаполненный реквизит = null → рендер откажет СПИСКОМ («заполните Анкету»); осознанно-пустое (не-плательщик НДС) = ''.

## Компилятор (`template-compiler.ts`)

Опечатки против реестра, неизвестные форматтеры/аргументы, `{No}` вне повтора; форма элемента повтора — через `extraPaths`. Периоды дат: kind поля `daterange` разворачивается в плоские ключи «X From»/«X To»/«X Days»/«X» (`expandDocFormValues` в shared) — глубоких путей в синтаксисе НЕТ намеренно. Сам «X» — печатная строка периода, и собирает её ВЫЗЫВАЮЩИЙ: в ней есть и слова, и формат даты, то есть язык бумаги.

## Сервисный API

`TemplateRenderService.render(buffer, values, {print})` / `compile(buffer, {extraPaths})` / `renderForContext(buffer, ctx, extraValues, {print})` / `systemRenderFileForContext(fileId, ctx, …)` — **system-контракт: право формировать проверяет вызывающий**. `print` (`printFor(language)`) обязателен: молчаливого языка по умолчанию у бумаги нет. PDF из заполненного .docx — ноль кода (rendition-путь core/docs).

`GET /templates/field-groups` — панель «Что подставить» конструктора. Дев-полигон `POST /templates/dev/render|compile|resolve` (только development).

## Почему свой драйвер (зафиксировано проверкой на живых файлах)

easy-template-x МОЛЧА ломает документ · docxtemplater: Excel — платный модуль, `undefined` без nullGetter · carbone: дата уезжает на день без timezone, закрытая лицензия v4+. Excel — вторым драйвером при Счетах (перенумеровка строк по образцу MIT xlsx-template).
