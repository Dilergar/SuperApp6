# Сотрудники (StaffModule, B2B)

> Справочники оргструктуры + назначения должностей. Три независимые оси (должность/отдел/филиал) проецируются в core/access.

## Модель

- **`StaffDepartment`** — Отдел; ДЕРЕВО через parentId (цикл → 400; UI пока плоский список с родителем).
- **`StaffPosition`** — Должность; опционально принадлежит отделу. **Членство в отделе — ПРОИЗВОДНОЕ от должности** (модель штатного расписания 1С) — прямого назначения «человек→отдел» нет.
- **`StaffBranch`** — Филиал (имя+адрес).
- **`StaffAssignment`** — человек × должность × опц. филиал; несколько на человека; статус `training→certified` (фундамент Додзё; переключает manager+).
- Дубль имени → 409 (unique на воркспейс); удаление должности/филиала с активными назначениями → 409. Удаление ОТДЕЛА не каскадит: должности отцепляются от отдела, подотделы уезжают в корень. Назначение должности Подрядчику → 400.

## Проекция в core/access

`position#holder@user` · `branch#member@user` · `department#member@user` **с closure предков** (грант на отдел достаёт подотделы); `resyncWorkspaceStaff` на каждую мутацию + `reconcileStaff` в AccessReconcileCron; `EPOCH_FANOUT` для трёх осей. Роли воркспейса → `member` маппингом; contractor НЕ проецируется.

## Гейты

Чтение справочников/ростера — команда (trainee+; Подрядчик → 403); запись (CRUD, назначения, аттестация, наём) — **manager+**; роли/увольнение — admin+ (админа — только владелец). Увольнение/выход — каскад: назначения + tuples снимаются.

## Факт vs юридический план

StaffAssignment — ФАКТ («как работает»); юридический план («как договорились» — договор, оклад, должность ПО ДОГОВОРУ) — `Employment` в КЭДО ([hr_kedo.md](hr_kedo.md)); расхождение = плашка-подсказка, не ошибка.

## API (кратко)

`GET /workspaces/:id/staff` (справочники одним ответом) · departments/positions/branches CRUD · `POST /members/:userId/assignments` · `PATCH /assignments/:id` (перевод/аттестация) · `DELETE /assignments/:id`.

## Веб

`/workspaces/[id]/members`: вкладки Сотрудники (фильтры; ростер — `StaffPersonCard` гридом как «Моё окружение»: карта L → XL-оверлей; бейдж карты = Должность, роль организации на карте НЕ показывается; «Написать» → DM; модалка управления у manager+: роль по лестнице + назначения + реквизиты + увольнение; «Сохранить» доводит правки) | Должности | Отделы | Филиалы | Приглашения (форма найма — клон формы «Добавить в окружение»: lookup по номеру → чипы Должность (одна) + Филиалы (несколько) → «всегда Стажёр»). EntitySelector-типы department/position/branch зарегистрированы с workspace-скоупными лоадерами.

TemplateFieldRegistry: группа «Сотрудник» (анкета + должность/отдел/филиал) — см. [templates_engine.md](templates_engine.md).
