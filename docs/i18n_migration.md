# Мультиязычность: глоссарий и список миграции

> Как переводить термины продукта и в каком порядке переводить сервисы. Устройство — в [i18n.md](i18n.md).
>
> Код: `packages/i18n/src/messages/` (каталоги), `apps/web/i18n.legacy.json`, `apps/api/i18n.legacy.json`.

## Глоссарий (en / kk / ru)

Термины продукта переводятся ОДИНАКОВО везде. Спорное — сюда, а не в память переводчика.

| en | kk | ru | Примечание |
|---|---|---|---|
| Circle | Айнала | Окружение | НЕ «Контакты»: слоя контактов в продукте нет |
| Group | Топ | Группа | Единица видимости внутри окружения |
| Organization | Ұйым | Организация | B2B-арендатор; в UI не «воркспейс» |
| Employees | Қызметкерлер | Сотрудники | Раздел организации |
| Site | Нысан | Объект | Физическая площадка сети |
| Work pass | Жұмыс рұқсаты | Рабочий пропуск | Роль человека в организации |
| Awaiting decision | Шешім күтуде | Ждут решения | Стопка `core/approvals` |
| Chronicle | Хроника | Хроника | Лента `core/chatter` |
| Drive | Диск | Диск | OmniDrive |
| Wallet | Әмиян | Кошелёк | Леджер |
| Coins | Коиндар | Коины | Внутренняя валюта человека |
| Trainee | Тағылымдамашы | Стажёр | Первая ступень лестницы ролей |
| Manager | Менеджер | Менеджер | Ранг ≥ 3 |
| Counterparty | Контрагент | Контрагент | Внешняя сторона договора |

## Список миграции

По сессии на сервис; ратчет не даёт списку расти.

Задачи → Календарь → Мессенджер (остальное) → Окружение →
Организации/Сотрудники/Оргструктура → Документы/Диск/Ссылки/Подпись → Объекты →
КЭДО → Финансы/Кошелёк/Магазин → Процессы → Заметки/Диктофон/Офис → провайдеры
рич-карт и поиск → остаток исключений API.

Отдельные треки: платформенный контент (бланки РК, «прописью» по-казахски —
крюк `TemplateRenderOptions.language` уже есть), FTS для kk (pg-kazsearch /
hunspell; trigram работает уже сейчас), RTL (физические `left/right` в CSS →
логические свойства), регион как настройка, `kk-Latn` как отдельная локаль с
транслитерацией из `kk`.

## Стражи

| Страж | Что держит |
|---|---|
| ESLint `i18n/no-cyrillic-literal` (`scripts/eslint-rules/no-cyrillic-literal.cjs`, подключён в 4 конфига) | Кириллица в литералах, шаблонах и тексте JSX. Комментарии не трогаются |
| Он же, `Program:exit` | Файл из `i18n.legacy.json`, в котором кириллицы уже НЕТ → «убери строку из списка». Ратчет только сокращается |
| `pnpm check:i18n` (`scripts/check-i18n.cjs`) | Файлы всех неймспейсов во всех локалях; паритет ключей en ⇔ kk ⇔ ru; разбор ICU; паритет плейсхолдеров и веток plural; `messages/index.ts` совпадает с диском. Предупреждения: неймспейс > 40 КБ, ключ не встречается в коде |
| Рантайм dev | next-intl `onError` → `console.error` при пропуске ключа; браузерная проверка «0 ошибок консоли» его ловит. `I18nService` логирует пропуск один раз на ключ |
| `verify-i18n.cjs` | e2e: отказ на языке запроса + `details.code`, `de` → kk, Zod, `User.locale`, перерисовка уведомления, `text`+`raw` хроники, плашка чата |

**Ратчет** (`i18n.legacy.json` в корне каждого пакета) — список ещё не
переведённых файлов. Он ТОЛЬКО сокращается; заполнен один раз
(`node scripts/gen-i18n-legacy.cjs`) и больше этим скриптом не пополняется —
без `--allow-grow` он откажется расти.

Постоянные исключения (с причиной в конфиге): `apps/web/src/app/dev/**` (витрина
кита), `packages/shared/src/constants/hr-library.ts` (бланки ТК РК — платформенный
контент), `apps/api/src/core/templates/template-formatters.ts` (DSL шаблонов),
`LOCALE_NAMES` (автонимы).
