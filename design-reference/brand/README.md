## Линия «Кольцо‑6»

Витрина со всеми вариантами и правилами — `showcase.html` (открыть локально или через
предпросмотр `brand-showcase` из `.claude/launch.json`). Статус: **отклонён пользователем**; в приложение (шапка `AppShell`, favicon, manifest) не внедрён.

Вторая линия концептов — бренд **«№6»**, падающая звезда рисует шестёрку: файлы `n6-*.svg`
(«Орбита», «Темірқазық», «N⁶» + шесть его вариаций с акцентом на 6 — `n6-numero-alt-*.svg`),
витрина `showcase-star6.html`, описание и SVG трёх концептов `concepts.json`, единственный
источник — генератор `gen-star6.cjs`. Статус: **отклонена пользователем** (ни один вариант не
подошёл), хранится для истории выбора.

## Идея

Семейство имён — SuperApp6, SuperAIAgent6, SuperTerminal6 — объединяет цифра, поэтому знак —
геометрическая «6»:

- **чаша** — круг, Окружение человека (фундамент всех сервисов);
- **точка внутри** — сам человек, один `user_id` на жизнь и работу;
- **хвост уходит вверх** — рост, выход наружу, к бизнесу.

Штрих одной толщины со скруглёнными концами — как иконки Phosphor Light; цвета — только из
палитры Organic Bento (`#588cd3` акцент, `#1d1b1d` чернила, `#fafbf8` блок, `#ffffff` на синем).

## Геометрия (квадрат 64)

- Чаша: окружность r14 с центром (32, 38).
- Хвост: дуга r26 с центром (44, 38) от вершины (44, 12) до левой точки чаши (18, 38) —
  центры лежат на одной горизонтали, поэтому в точке стыка касательные совпадают.
- Штрих 7/64, `stroke-linecap: round`; точка r4.5 в центре чаши.
- Path: `M44 12A26 26 0 0 0 18 38A14 14 0 1 0 46 38A14 14 0 1 0 18 38`.

## Правила применения

- Охранное поле — половина ширины чаши (14/64 высоты знака) со всех сторон.
- Минимум: знак 16 px (без точки), словесный знак 20 px высоты, штриховая версия 96 px.
- Ниже 24 px точка убирается, штрих 8/64 (иначе чаша забивается).
- Не наклонять, не менять толщину штриха, не растягивать, не красить в цвета статусов,
  не ставить тень. Синий знак — на светлом и тёмном; белый — только на синей плитке.
- В словесном знаке цифра всегда синяя и всегда геометрическая — то же для имён семейства.

## Пересборка

```bash
node design-reference/brand/gen-brand.cjs
```

Генератор — единственный источник правды: геометрия, палитра и раскладка лок‑апов живут в нём,
SVG и `showcase.html` руками не правятся. Шрифт `Manrope-latin-variable.woff2` (OFL 1.1) лежит
рядом — копия латинского сабсета, который `next/font` отдаёт вебу. Контуры извлекает `fontkit`
из зависимостей `pdf-lib` (в скрипте — обход двух его багов с WOFF2 + вариациями веса).
