# Компоненты: логика и поведение (для точного воспроизведения)

Размеры/отступы — на усмотрение разработчика. Важно: цвета из README (фон `#eae6de`, блоки `#fafbf8`, матовые заливки) и корректное поведение, описанное ниже. Все стили hover/active — transition 0.15–0.2s.

## 1. Date Picker
Состояние: `selectedDay: number`.
- Сетка 7 колонок, неделя с понедельника. Перед 1-м числом — пустые ячейки по дню недели 1-го числа (июль 2026 → среда → 2 пустых).
- Клик по дню → `selectedDay = d`. Выбранный: заливка `#588cd3`, текст белый. «Сегодня»: тонкий бордер `rgba(88,140,211,0.5)`, текст `#3f6aa8`; если сегодня выбран — стиль выбранного.
- Пустые ячейки некликабельны и невидимы.
- Кнопки ‹ › в шапке меняют месяц (в прототипе — заглушки; в проде пересчитать offset и число дней).
- Грабля: ячейкам-кнопкам нужно `padding:0; min-width:0`, иначе grid переполняет контейнер.

## 2. Pagination
Состояние: `page: number` (1..N, N=6).
- Клик по номеру → `page = n`. Стрелки: `page = clamp(page ± 1, 1, N)` — на границах не выходят за диапазон (кнопку можно дизейблить или просто клампить).
- Активная страница: матовая синяя (bg `rgba(88,140,211,0.14)`, бордер `rgba(88,140,211,0.35)`, текст `#3f6aa8`); остальные прозрачные, hover-подложка.
- Подпись «Page X of N» обновляется. Контейнер с `flex-wrap` — не должен обрезаться на узких ширинах.

## 3. Text Scramble
Состояние: отображаемая строка. Параметры: `chars = '!<>-_/[]{}=+*^?#'`, фразы циклом: ['Risk Survey 2026', 'Text Scramble FX', 'SuperApp Modules'].
Алгоритм:
```js
// interval 40ms; frame++
reveal = floor(frame / 3);            // ~3 кадра на символ
out = target.slice(0, reveal)         // раскрытые символы
    + случайные chars для остальных позиций (новые каждый кадр);
// когда reveal >= target.length: стоп, через 2600ms — следующая фраза
```
- Кнопка replay — перезапуск со следующей фразы.
- Обязательно: очищать interval/timeout при unmount; пауза, когда компонент не виден (не рендерить кадры).
- Зарезервировать высоту блока (min-height), чтобы вёрстка не прыгала.

## 4. Slider
Состояние: `value: 0..100` (дефолт 40).
- Нативный `<input type="range">` c `accent-color:#588cd3`, событие `input` (не `change`) → обновляет значение live.
- Синхронно обновляются: числовой лейбл `{value}%` (цвет `#3f6aa8`) и штриховой tick-бар-превью с шириной заливки `{value}%` (рецепт tick-бара в README).

## 5. Alert
Состояние: видимость каждого алерта `{success, warning, danger}` = true.
- Три варианта (матовые, см. палитру README): success — иконка check-circle; warning — warning(треугольник); danger — warning-circle. Текст тем же цветом, что иконка.
- Крестик → скрывает только свой алерт (без анимации достаточно; допустим fade/collapse).
- Кнопка reset (стрелка-«назад») в шапке карточки → все три снова видимы.

## 6. Drag & Drop (upload)
Состояние: `dragActive: boolean`; список файлов.
- Зона: `border: 2px dashed #ddd6c8`, радиус 16. События:
  - `dragover` → `preventDefault()` (обязательно, иначе drop не сработает) + `dragActive = true` → бордер `#588cd3`, фон `rgba(88,140,211,0.06)`
  - `dragleave` → `dragActive = false`
  - `drop` → `preventDefault()`, `dragActive = false`, добавить файлы из `e.dataTransfer.files`
- «browse files» — синяя ссылка, открывает скрытый `<input type="file">`.
- Строка файла: завершённый — матовая зелёная иконка + подпись «N MB · COMPLETE» зелёным + кнопка удаления (trash); загружающийся — имя + `{percent}%` + tick-бар прогресса + крестик-отмена.
- **Бар загрузки — градиент красный→зелёный** (`#de6d68 → #d6a04c → #74a277`): градиент фиксирован на всю ширину бара, заполнение открывает его слева направо (3-слойный рецепт из README). При 100% строка переходит в состояние «COMPLETE».

## 7. Gradient Progress (2 варианта)
Статичные индикаторы-показатели:
- «Risk exposure»: градиент зелёный→красный (`#74a277 → #d6a04c → #de6d68`), значение красным.
- «Mitigation coverage»: градиент красный→зелёный, значение зелёным.
- Оба — штриховые (tick), градиент по всей шкале, непройденная часть — серые тики `#e4ded1`.

## 8. Toggle (switch)
Состояние: boolean на каждый тумблер.
- Трек-пилюля: **ON = `#74a277` (зелёный)**, OFF = `#ddd6c8`. Белый круглый кноб сдвигается вправо (`translateX`), transition 0.2s на фон и transform.
- Клик по всему тумблеру переключает. В проде — role="switch", aria-checked.

## 9. Дерево в сайдбаре
Состояние: `treeOpen: boolean`; активный узел.
- Клик по «Projects»: если раздел уже открыт — toggle дерева; если нет — открыть раздел и развернуть дерево. Карет вращается 180°.
- Клик по листу (Risk Survey) → открывает его страницу.
- Подсветка пути к активному листу: родительский пункт («Projects») — светлая подложка `#f1ede3`; промежуточный узел («Survey Data») — тёмный текст/иконка `#1d1b1d`; линии-колена пути — `#b3a98f` (обычные — `#ddd6c8`); сам лист — пилюля `#ece7dc`.
- Линии: 1px, колена скруглены (border-left + border-bottom + border-bottom-left-radius); вертикальные стволы непрерывны между уровнями.

## 10. Общее
- Чекбоксы задач: `accent-color:#588cd3`; отмеченная задача — opacity ~0.65 + line-through.
- Поиск: focus → бордер `#588cd3` + ring `rgba(88,140,211,0.15)`.
- Сайдбар скроллится, если контент выше окна (не обрезать нижние пункты).
