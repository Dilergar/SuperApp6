# Дизайн-система: Organic Bento (warm matte)

Действует с 2026-07-27. ЗАМЕНИЛА прежнюю «Digital Atelier / Живой скетчбук» целиком.
Правда — `DESIGN.md` в корне. Исходный дизайн-пакет-референс — `design-reference/`
(README.md пакета, COMPONENTS.md, HTML-прототип 3 экранов + support.js).

## Несущее
- Фон страницы `#eae6de`, ВСЕ блоки/карточки/сайдбар `#fafbf8` — зафиксировано пользователем, не менять
- Шрифт **Manrope** везде, через `next/font/google` (самохостится → совпадает с CSP `font-src 'self'`;
  раньше `@import` тянул шрифты с Google в обход собственного CSP)
- Акцент и бренд — синий `#588cd3`, тёмный вариант текста на матовом `#3f6aa8`
- **Красный `#de6d68` — только опасное действие.** Бренд больше не красный
- Успех `#74a277`/`#3c6842`, предупреждение `#d6966c`/`#9a5f2f` (база/текст)
- Иконки — Phosphor Light ТОЛЬКО через `<Icon/>` (`apps/web/src/components/ui/Icon.tsx`,
  реестр `ICONS` семантических ключей). Прямой импорт из `@phosphor-icons/react` в страницах запрещён.
  Пользовательские эмодзи из БД (Circle.icon, Currency.icon, FinAccount.icon, Listing.icon,
  WishItem.icon) — это ДАННЫЕ, показываются `<EmojiIcon/>` в матовом круге
- Радиусы ровные: карточка 24, панель 20, кнопка/поле 12, пункт меню 14, пилюля 999
- Одна тень `0 4px 20px rgba(0,0,0,0.04)`; 1px-бордеры `#e2dccf` — несущие
- Фирменный прогресс — штриховой (tick): штрихи 2px с шагом 5px (`.tick-bar`, `.tick-bar-grad`)
- Две плотности: просторная по умолчанию, `.density-compact` для чата/таблиц/календаря/лент

## Отменено (не возвращать)
Кривые радиусы, наклон карточек, шум-текстура «бумага», восковые мазки, акварельные
wash-эффекты, запрет на 1px-бордеры, шрифты Epilogue и Plus Jakarta Sans.

## Где живут токены
`apps/web/src/app/globals.css`. СТАРЫЕ имена переменных сохранены намеренно
(`--primary`, `--radius-sketch`, `--font-display` и др.): ими пользуются ~2600 мест
в 125 файлах, и переназначение значений перекрасило приложение целиком, не трогая страницы.
Доменные цвета (статусы задач, приоритеты, цвета событий, редкость скинов, пресеты Групп)
живут в `packages/shared/src/constants/{tasks,calendar,contacts,card-skin}.ts` — они общие
для API, веба и мобильного, и тоже переведены на новую палитру.

## Правило компонентов
Единственный источник примитивов — `apps/web/src/components/ui/`. Страницам запрещено
рисовать свои кнопки/поля/модалки/чипы; не хватает — расширяется кит (Принцип 1, как у
платформенных движков). Каталог состояний — страница `/dev/ui` (dev-only).
Человек в UI — всегда одна из 5 карточек (`PersonChip`/`PersonAvatar`), не голым текстом.

## Реестр ICONS: расширения 2026-07-27
Ключ описывает СМЫСЛ, поэтому два ключа на один рисунок — норма:
`position` (Briefcase, должность), `department` (UsersFour, отдел),
`branch` (MapPin, филиал), `location` (MapPin, место события/встречи).

## Что НЕ переводится на кит (решение зафиксировано)
- **Паспорта нод Процессов** (`ProcessNodeTypeDto.icon` — эмодзи 🚀 ⏰ 🌐 …):
  приходят с бэкенда, читаются палитрой и нодами канваса; это контракт паспорта
  (его же получат AI/MCP-поверхности) → правится в движке Процессов, не в вёрстке.
- **Визуальный язык канваса**: цвета категорий нод, типизированные порты, бейджи
  статуса внутри ноды (`CATEGORY_COLORS`, `PORT_COLORS`, `STEP_STATUS_BADGE` в
  `process-lib.ts`). Вне канваса статусы — чипы кита по `INSTANCE_STATUS_TONE`/
  `STEP_STATUS_TONE` из того же файла.
