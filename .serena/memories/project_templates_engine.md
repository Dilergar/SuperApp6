# core/templates — заполнение шаблонов документов СВОИМ драйвером (Этап 3 «Документов», 2026-08-03)

Тонкая подсистема БЕЗ своих таблиц и миграций. `verify-templates.cjs` **70/0** (включая смоук:
живая Collabora конвертирует файл нашего драйвера в PDF — валидность подтверждена настоящим
Word-движком), регрессии requisites/staff/approvals зелёные.

## Решение «свой драйвер» (пользователь, 2026-08-03)

Готовые отвергнуты проверкой на живых файлах: **easy-template-x** молча ломает документ
(потерянная колонка, незакрытые теги), у **docxtemplater** Excel/картинки — ПЛАТНЫЕ модули,
у **carbone** дата `2026-09-01` без timezone выходит `31.08` и лицензия с v4 закрыта (копировать
можно только из v3 Apache-2.0). Скоуп: **Word сейчас** (ядро формат-агностично), **Excel — второй
драйвер при счетах** (перенумеровка строк — по образцу MIT `xlsx-template`), **PDF — ноль кода**
(заполненный .docx конвертирует существующий rendition-путь core/docs). Слой сменности: шаблоны
клиентов написаны на НАШЕМ синтаксисе — упрёмся в край, docxtemplater подключается запасным
драйвером без переделки шаблонов.

## Архитектура

- **Синтаксис** (shared/constants/templates.ts): `{Организация.БИН}`, форматтеры цепочкой
  `{Поле|дата:долгая}`, повтор строки таблицы `{#Строки}…{/Строки}` + `{№}` (номер с 1).
- **Драйвер** `docx-render.driver.ts` (~600 строк, fflate): текст-узлы `<w:t>` → «виртуальный
  текст» с картой смещений → тег, разорванный Word'ом на прогоны, СОБИРАЕТСЯ; между абзацами /
  `<w:br/>` / рисунками / полями — сентинел `\u0000`, через него тег честно не собирается
  (`tag_broken_by_break`). Замена — хирургия только внутри `<w:t>` (значение в ПЕРВЫЙ узел =
  наследует форматирование, остальные пустеют), многострочность — настоящие `<w:br/>`,
  узел пересобирается с `xml:space="preserve"`. Повтор: объемлющий `<w:tr>` ищется стеком
  интервалов, строка клонируется на элемент, скоуп = поля элемента → глобальные, `{№}` = i+1.
  Порядок рендера: структура ВСЕХ частей (полный список ошибок за заход) → сплайсы повторов
  с конца → обычная подстановка (остаточные маркеры затираются).
- **Ошибки только громкие**: `TemplateCompileError{issues[]}` / `TemplateDataError{missing[]}`;
  «undefined» в документе невозможен. Не-строгий режим (`strict:false`) оставляет недостающие
  теги ВИДИМЫМИ (для превью).
- **Форматтеры**: `дата`/`дата:долгая` (строка YYYY-MM-DD разбирается КАЛЕНДАРНО без таймзон —
  регрессия Carbone закрыта тестом; Date-моменты через APP_TIMEZONE), `прописью` (тенге/тиын,
  триады с женским родом тысяч), `прописью:число`, `число` (пробелы-разряды, запятая-дробь).
- **Реестр** `TemplateFieldRegistry.register({key, tagPrefix, fields, resolve(ctx)})` в
  onModuleInit (паттерн FilesRefRegistry): Workspaces → «Организация» (12 полей: реквизиты,
  основной счёт, директор-ФИО), Staff → «Сотрудник» (14 полей: анкета + первое назначение).
  **Контракт честности: незаполненное = null → отказ списком; осознанно-пустое = ''**
  (не-плательщик НДС). Тумблеры «Видимости в Компаниях» в резолверах НЕ действуют осознанно —
  право формировать проверяет потребитель (Этап 4), документ печатает реквизиты по определению.
- **Компилятор** `template-compiler.ts`: сверка с реестром (опечатки группы/поля), неизвестные
  форматтеры/аргументы, `{№}` вне повтора; голые поля ВНУТРИ повтора не проверяются (форму
  элемента принесёт Этап 4 через `extraPaths`).
- **API**: `GET /templates/field-groups`; dev-полигон `POST /templates/dev/render|compile|resolve`
  (только development, прецедент jobs/approvals); сервисные `TemplateRenderService.render /
  compile / renderForContext / systemRenderFileForContext` (**system-контракт**).

## Ловушки сессии

- **Claude при записи `'\u0000'` в Write/replace_content ЭМИТИТ ЛИТЕРАЛЬНЫЙ NUL-БАЙТ** (дважды
  подряд!) — файл становится «бинарным» для ripgrep и молча выпадает из всех поисков (та же
  ловушка, что в access.service.ts при стройке approvals). Детерминированное лечение — PowerShell:
  `$c.Replace([string][char]0, '\u0000')` (одинарные кавычки PS не интерпретируют backslash).
  В regex-режиме replace_content репл `\\u0000` даёт ДВА бэкслеша в файле.
- Смоук валидности рендера бесплатен: upload профилем `document` → `POST /docs/from-file` →
  `POST /docs/:id/rendition {target:'pdf'}` — Collabora отвергла бы битый ZIP/XML.
- Минимальный валидный .docx строится в скрипте fflate'ом (Content_Types + .rels +
  document.xml.rels + document.xml + header1.xml с headerReference) — образец в
  verify-templates.cjs; заголовок обязан быть провязан relationship'ом.
- `MONTH_NAMES_RU` в shared УЖЕ в родительном падеже («августа») — для «3 августа 2026 г.»
  ничего добавлять не пришлось.

## Дальше (Этап 4)

Сервис «Документы» строит DocType/DocTemplate/OrgDocument, передаёт `extraPaths` (поля формы +
ключи коллекций) в компилятор при сохранении шаблона, зовёт `systemRenderFileForContext` в джобе
`documents.generate`, группа «Документ» (номер/дата/поля формы) регистрируется там же.
Пост-проверка формирования = конвертация результата в PDF + «не осталось `{`» (смоук-паттерн).
