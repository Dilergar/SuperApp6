# Пак значков и выборщик (`infra/glyph-pack` + кит)

Построено 2026-07-28. Один выборщик значка на всё приложение + один рендерер.

## Модель

Значок хранится ОДНОЙ строкой (те же 6 таблиц, миграций НЕТ), значение несёт
пометку набора:

| Значение | Что это | Чем рисуется |
|---|---|---|
| `ph:car` | предметная иконка каталога (453, Phosphor Light) | контур из `/glyphs/icons.json` |
| `fl:1f697` | эмодзи «Свои» (Fluent Color, 1595) | `/glyphs/fluent/<кодпоинт>.webp` |
| `nt:1f697` | эмодзи Noto (весь стандарт, 1914) | символ шрифтом Noto Color Emoji |
| `receipt` | имя иконки КИТА (значок ставит КОД) | `<Icon/>` |
| `🚗` | голый символ (записи до выборщика) | тот же шрифт Noto |

**Набор — свойство КАЖДОГО значка**, не глобальная настройка: решение продукта
(«не нашёл в Noto — посмотрел в Fluent и выбрал там»). Поэтому пометка в
значении, а не колонка `iconPack` в шести таблицах.

Потолки длины подняты 16 → 64 (FIN/SHOP/WALLET_LIMITS + validation/circle):
`fl:1f469-200d-1f4bb` в 16 символов не влезал.

## Компоненты кита

- `Glyph` — ЕДИНСТВЕННОЕ место разбора значения. До него логика «имя иконки или
  эмодзи?» была скопирована 4 раза (FinGlyph, EntityGlyph, CardGlyph, MenuGlyph),
  и каждая копия знала про два случая из пяти. Все переведены на него.
- `EmojiIcon` — тот же Glyph в матовом круге; ПЕРЕЕХАЛ из Icon.tsx в Glyph.tsx
  (иначе кольцо импортов), из кита экспортируется по-старому.
- `GlyphField` (поле формы) · `GlyphPicker` (панель) · `GlyphPickerButton`
  (кнопка-триггер, композер чата).
- `Chip` и `Select` получили проп `glyph` — значок любого набора в чипе/опции.

Просмотр — по одному каталогу (сегмент + категории), **поиск — по всем трём
секциями**. `suggest` подставляет в поиск название сущности, `only` фиксирует
каталог (чат берёт `only="noto"`), `keepOpen` — набор нескольких подряд.

## Сборка (infra/glyph-pack)

`build.ps1` → `build.cjs`, пины в `pins.env`. Четыре источника: Fluent Emoji
(MIT, sparse-клон только Color), `@phosphor-icons/core` (MIT), `emojibase-data`
(MIT, русские названия CLDR), `@fontsource/noto-color-emoji` (OFL-1.1).
Каталог иконок курируется РУКАМИ — `icons.catalog.json` (имя + русское название
+ синонимы); несуществующее имя валит сборку.

## Решения и ловушки

- **Fluent растеризуется в webp 128px, а не остаётся SVG.** Исходные Color-SVG —
  25 КБ в среднем, весь набор 38 МБ, экран сетки тянул бы 1.5 МБ. После
  растеризации значок 2.7 КБ, пак 4.3 МБ, экран ~160 КБ.
- **Иконки — строкой контура в JSON.** Все 1512 Light-иконок Phosphor это ровно
  один `<path>` в `0 0 256 256`. React-компоненты утащили бы 453 иконки в граф
  каждой страницы; внешний `<use href="sprite.svg#id">` — разночтения в Safari.
- **У Fluent НЕТ флагов стран** (только 13 «флажковых»: клетчатый, пиратский,
  радужный). 270 флагов, включая 🇰🇿, есть только в Noto. Плюс 319 свежих эмодзи
  Юникода — тоже только Noto. Это не поломка сборки.
- **Шрифт — официальная сборка COLRv1, пережатая нами в woff2** (`wawoff2`,
  Node/WASM): один файл 1.88 МБ, `font-display: swap`, вечный кэш (заголовок в
  `next.config.ts` для `/glyphs/:path*` — Next по умолчанию отдаёт /public БЕЗ
  кэша). **Готовый `@fontsource/noto-color-emoji` НЕ ГОДИТСЯ** (наступил и
  откатил): его нарезанные по unicode-range сабсеты в Chromium рисуют ПУСТОТУ.
  Диагностика неочевидна — глиф в сабсете есть, поэтому браузер не откатывается
  на системный шрифт, `document.fonts.check` возвращает true, консоль чиста, а
  вкладка эмодзи выглядит пустой. Единственная честная проверка — нарисовать
  эмодзи в canvas и посчитать закрашенные пиксели (0 против 940).
- **`'Noto Color Emoji'` в стеке стоит ПОСЛЕ Manrope.** Поставить первым нельзя:
  в эмодзи-шрифте есть цифры и решётка (сабсет 2 несёт U+30-39, U+23), и
  клавиатурные значки поехали бы им.
- **В чат вставляется САМ символ**, а не пометка набора: сообщение остаётся
  обычной строкой. Поэтому чат-выборщик показывает только Noto — сетка Fluent
  обещала бы картинку, которой в сообщении не будет.
- `npm pack` из Node на Windows требует `shell: true` (Node с 18.20 не запускает
  `.cmd` без shell).
