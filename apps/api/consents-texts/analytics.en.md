# Usage Analytics

## 1. What is recorded

{{legalName}} (the Operator) records platform usage events: a section opened, a button pressed, a step completed. An event contains the action code, the time, the device type and the account identifier. The content you create — messages, notes, files, names of people — does not get into events.

## 2. Why

To find inconvenient places, to count which services are in demand and to check that changes make the platform better. Analytics data is not sold or transferred to third parties; it is processed on the Operator's servers in the Republic of Kazakhstan.

## 3. How to opt out

Usage analytics is on by default. You can turn it off in the "My data" section of the profile — after that interface action events stop being recorded on the server side. The browser signal "Global Privacy Control" is honoured in the same way as an opt-out.

## 4. What is always recorded

Facts of service operation — registration, task creation, a deal, acceptance of a consent — are part of the services and of record keeping, so they are recorded regardless of this switch.

## 5. Retention

Raw events are kept for a limited period and then deleted; aggregates contain no information about a specific person. When the account is deleted, the events related to it are deleted. Contact: {{privacyEmail}}.
