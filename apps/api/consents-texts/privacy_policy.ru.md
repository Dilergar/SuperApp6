# Политика обработки персональных данных

Утверждена оператором в соответствии с подпунктом 1-1) пункта 2 статьи 25 Закона Республики Казахстан «О персональных данных и их защите».

## 1. Оператор и ответственное лицо

Оператор — {{legalName}}, БИН {{bin}}, адрес: {{address}}. Лицо, ответственное за организацию обработки персональных данных, — {{dpoTitle}} оператора. Обращения субъектов: {{privacyEmail}}.

## 2. Принципы

- данные обрабатываются только для заявленных целей и в необходимом объёме;
- основание обработки — согласие субъекта либо прямое требование закона;
- база с персональными данными хранится на территории Республики Казахстан;
- данные хранятся не дольше, чем нужно для цели, а затем уничтожаются или обезличиваются;
- доступ получают только те, кому он нужен для работы, и каждое обращение записывается.

## 3. Перечень персональных данных

Идентификационные: номер телефона, фамилия, имя, отчество, дата рождения, фотография. Дополнительные, по желанию пользователя: город, сведения о себе, электронная почта, семейное положение, ссылки на социальные сети. Реквизиты для договоров и трудоустройства, по желанию: ИИН, адрес проживания, данные удостоверения личности. Содержимое пользователя: сообщения, задачи, заметки, файлы, документы. Технические: IP-адрес, сведения об устройстве, идентификаторы сессий, токены уведомлений. Биометрические данные не обрабатываются.

## 4. Роли оператора

Для данных пользователей оператор является собственником базы и оператором. Для данных, которые в платформу вносит организация (сотрудники, контрагенты, клиенты), собственником является организация, а оператор обрабатывает их по её поручению — на условиях «Соглашения об обработке персональных данных».

## 5. Меры защиты

- шифрование персональных данных в базе ключами, управляемыми отдельным движком; у каждого человека и каждой организации свой ключ;
- слепые индексы вместо открытых значений там, где нужен поиск;
- разграничение прав: доступ к объекту определяется связью человека с ним;
- отдельный контур для сотрудников оператора: вход с подтверждением по SMS, повторное подтверждение опасных действий, правило «четырёх глаз», неизменяемый журнал;
- журналы действий с персональными данными, включая журнал раскрытия данных сотрудникам;
- передача данных только по защищённым каналам;
- учёт передач третьим лицам, трансграничных передач и распространения;
- резервное копирование и контроль целостности.

## 6. Передача данных

Перечень получателей приведён в «Согласии на сбор и обработку персональных данных» и в «Согласии на трансграничную передачу». Каждая фактическая передача записывается; пользователь видит свои записи в разделе «Мои данные».

## 7. Сроки хранения

Данные аккаунта — до удаления аккаунта. После запроса на удаление аккаунт скрыт 14 дней (можно восстановить), затем данные уничтожаются или обезличиваются. Дольше хранятся только сведения, срок хранения которых установлен законом: записи о финансовых операциях, подписанные документы, доказательства данных согласий, сведения о нарушениях правил — с ограничением доступа.

## 8. Права субъекта

Знать о наличии и составе своих данных; получать их; требовать изменения, блокирования и уничтожения; отозвать согласие; обжаловать действия оператора в уполномоченный орган или суд. Запросы исполняются в сроки, установленные Законом.

## 9. Нарушение безопасности

Обнаружив нарушение безопасности персональных данных, оператор в течение одного рабочего дня уведомляет уполномоченный орган и затем затронутых субъектов, сообщая, что произошло, какие данные затронуты и что следует сделать. Инциденты ведутся в отдельном журнале.

## 10. Изменение политики
