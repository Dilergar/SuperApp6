# Соглашение об обработке персональных данных

Заключается между Организацией (собственником базы, содержащей персональные данные) и {{legalName}}, БИН {{bin}}, адрес: {{address}} (оператором, действующим по поручению), в соответствии с Законом Республики Казахстан «О персональных данных и их защите».

## 1. Роли

1.1. **Организация — собственник.** Она определяет цели и состав персональных данных своих сотрудников, кандидатов, клиентов, контрагентов и их представителей, которые вносит в рабочее пространство, и отвечает за законность их сбора, в том числе за получение согласий субъектов.

1.2. **Оператор платформы обрабатывает эти данные по поручению Организации** — только для предоставления функций платформы и только по её указаниям, которыми являются действия Организации и её сотрудников в интерфейсе и через API.

1.3. В отношении личных аккаунтов людей (номер телефона, профиль, личное пространство) оператор действует самостоятельно — на основании согласия самого человека. Эти данные Организации не принадлежат.

## 2. Предмет поручения

Хранение, систематизация, отображение, передача внутри рабочего пространства по правам, установленным Организацией, формирование документов, направление уведомлений, резервное копирование, уничтожение.

## 3. Обязанности оператора

- обрабатывать данные только для целей этого соглашения и не использовать их в собственных целях;
- хранить базу на серверах в Республике Казахстан;
- шифровать персональные данные Организации ключом, принадлежащим этой Организации; заморозка или уничтожение ключа делает данные нечитаемыми;
- допускать к данным своих сотрудников только в необходимых случаях (поддержка по обращению, безопасность), с отдельным подтверждением, указанием причины и записью в неизменяемый журнал;
- вести учёт передач данных третьим лицам;
- помогать Организации отвечать на запросы субъектов — средствами платформы (поиск, выгрузка, исправление, удаление).

## 4. Привлечённые лица

Оператор вправе привлекать к обработке третьих лиц только по этому перечню и отвечает перед Организацией за их действия:

| Лицо | Страна | Для чего |
|---|---|---|
| ТОО «КазИнфоТех» | Казахстан | отправка SMS (коды, ссылки на подпись, уведомления) |
| АО «Национальные информационные технологии» — НУЦ РК | Казахстан | проверка электронной цифровой подписи |
| Службы доставки push-уведомлений (Google, Mozilla, Apple, Microsoft) | США | доставка уведомлений на устройства сотрудников — на основании их личного согласия |

Адреса вебхуков задаёт сама Организация: данные на них передаются по её поручению, и получатель считается привлечённым ею, а не оператором. Об изменении перечня оператор уведомляет заранее — публикацией новой версии этого соглашения.

## 5. Нарушение безопасности

Обнаружив нарушение безопасности, затронувшее данные Организации, оператор уведомляет её владельца и администраторов без промедления, сообщая известные обстоятельства: что произошло, какие данные затронуты, какие меры приняты. Уведомление уполномоченного органа и субъектов в отношении данных Организации — обязанность Организации как собственника; оператор оказывает содействие и предоставляет сведения из своих журналов.

## 6. Срок, возврат и уничтожение

6.1. Соглашение действует, пока существует организация на платформе.

6.2. До удаления организации Организация вправе выгрузить свои данные. После удаления организация находится в архиве в течение установленного срока (восстановление возможно), затем данные уничтожаются, а ключи шифрования уничтожаются безвозвратно.

6.3. Сохраняются только сведения, хранить которые оператор обязан по закону (платёжные документы, подписанные сторонами документы и доказательства подписания), — с ограничением доступа.

## 7. Проверка

Организация вправе запросить у оператора сведения о мерах защиты и о привлечённых лицах. Запросы направляются на {{privacyEmail}}.

## 8. Ответственность

Ответственность сторон определяется «Условиями для организаций». Каждая сторона отвечает перед субъектами и уполномоченным органом за ту часть обработки, которую определяет сама.
