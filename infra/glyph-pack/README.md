# Пак значков SuperApp6 — рунбук

Здесь собирается всё, из чего человек выбирает **значок** сущности (категория
Финансов, своя валюта, витрина, лот, хотелка, Группа окружения) и эмодзи в чате.

Собранный результат **лежит в репозитории** (`apps/web/public/glyphs/`) — сборка
нужна только при смене пинов или правке каталога иконок, а не при каждом `pnpm install`.

```powershell
.\infra\glyph-pack\build.ps1                 # всё: эмодзи + иконки + шрифт
.\infra\glyph-pack\build.ps1 -Only icons     # быстро, после правки icons.catalog.json
.\infra\glyph-pack\build.ps1 -SkipFetch      # без сети, на уже скачанном в work/
.\infra\glyph-pack\build.ps1 -Force          # перекачать и перерисовать всё
```

## Что получается

| Выход | Что это | Размер |
|---|---|---|
| `apps/web/public/glyphs/fluent/<кодпоинт>.webp` | 1595 эмодзи «Свои» (Fluent Color, 128px) | ~4.3 МБ |
| `apps/web/public/glyphs/font/noto-color-emoji-colrv1.woff2` | Noto Color Emoji + `OFL.txt` | 1.88 МБ |
| `apps/web/public/glyphs/icons.json` | контуры 453 предметных иконок (`имя → path d`) | ~240 КБ |
| `apps/web/public/glyphs/index.json` | каталог для поиска: эмодзи и иконки с русскими названиями | ~270 КБ |
| `apps/web/src/app/noto-emoji.css` | `@font-face` с `unicode-range` на наши файлы | ~4 КБ |

Три каталога живут рядом намеренно: человек ищет «машина» и видит **сразу все
варианты** — нашу иконку, картинку Fluent и символ Noto, — и берёт тот, что
нравится. Набор запоминается у КАЖДОГО значка, глобального переключателя нет.

## Почему именно так

**Эмодзи «Свои» — картинками, а не SVG.** Исходные Color-SVG у Fluent весят
в среднем 25 КБ (градиенты и фильтры), весь набор — 38 МБ. Один экран сетки
выбора тянул бы полтора мегабайта. После растеризации в 128px/webp значок весит
2.7 КБ, весь пак — 4.3 МБ, экран сетки — ~160 КБ. 128px хватает: самый крупный
круг в интерфейсе 56px, то есть 112px при DPR 2.

**Эмодзи Noto — шрифтом, а не картинками.** Тем же файлом рисуются и выбранные
значки, и эмодзи внутри текста сообщений: подмена символов картинками в тексте
потребовала бы разбирать каждую строку в каждом месте рендера.

Берём ОФИЦИАЛЬНУЮ векторную сборку COLRv1 из репозитория `googlefonts/noto-emoji`
и жмём в woff2 сами (`wawoff2`, Node/WASM — Python с fonttools сборке не нужен).
Готовый `@fontsource/noto-color-emoji` **не годится**, хотя выглядит удобнее: его
нарезанные по `unicode-range` сабсеты в Chromium рисуют ПУСТОТУ. Ловушка в том,
что это не «шрифт не загрузился»: глиф в сабсете формально есть, поэтому браузер
даже не откатывается на системный — вкладка эмодзи просто оказывается пустой, и
на неё нельзя посмотреть «загрузился ли шрифт» (`document.fonts.check` вернёт
`true`). Единственная честная проверка — нарисовать эмодзи в canvas и посчитать
закрашенные пиксели (у сабсетов было 0, у COLRv1 — 940).

**Иконки — строкой контура в JSON, а не React-компонентами и не спрайтом.**
Все 1512 иконок Phosphor Light — ровно один `<path>` в системе координат
`0 0 256 256`, поэтому клиенту достаточно строки `d`. React-компоненты утащили
бы 453 иконки в бандл каждой страницы; внешний `<use href="sprite.svg#id">` —
это ещё и разночтения в старых Safari. JSON грузится один раз и кэшируется.

**Иконки курируются руками** (`icons.catalog.json`): только предметные и
смысловые (транспорт, еда, дом, животные, деньги…), с русскими названиями и
синонимами. Интерфейсных («закрыть», «фильтр», «стрелка») здесь нет — они живут
в реестре кита `components/ui/Icon.tsx`, и выбирать их человеку незачем.
Несуществующее имя валит сборку: дыр в паке молча не бывает.

## Ловушки

- **У Fluent нет флагов стран.** В наборе Microsoft всего 13 «флажковых» эмодзи
  (клетчатый, пиратский, радужный…), а 270 флагов государств — только в Noto.
  Это не ошибка сборки: `🇰🇿` ищется и выбирается на вкладке Noto.
- **319 эмодзи без картинки Fluent** — свежие добавления Юникода и часть
  составных (ZWJ). Они тоже доступны, но только в Noto. Флаг `hasFluent` в
  каталоге отвечает ровно за это.
- **После смены пинов нужен `-Force`.** Без него уже существующие `.webp` не
  перерисовываются (так повторный прогон занимает секунды вместо минут), и
  картинки останутся от прошлой версии.
- **`du` покажет 7.3 МБ вместо 4.3 МБ** на папке `fluent/` — это кластеры NTFS
  на 1595 мелких файлах. В git и по сети едет реальный размер.
- **Шрифт проверяется пикселями, а не фактом загрузки.** Если однажды соберётся
  «пустой» вариант, ни консоль, ни `document.fonts` об этом не скажут — эмодзи
  просто исчезнут с экрана. Проверка: `ctx.font='32px "Noto Color Emoji"'`,
  `fillText('😀')`, посчитать пиксели с ненулевой альфой.
- **Растеризацией занимается `sharp` из `apps/api/node_modules`** — тот же, что
  в конвейере файлов. Отдельной зависимости у скрипта нет; если `pnpm install`
  не прогонялся, сборка честно об этом скажет.
- **`work/` не в репозитории** (`.gitignore`): клон Fluent — 44 МБ, распакованные
  пакеты — ещё около 60 МБ. Едет только результат.
