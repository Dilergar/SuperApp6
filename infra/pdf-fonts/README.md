# Шрифты печатных документов (PDF-рендер конструктора)

PT Serif (ParaType, лицензия OFL — файл OFL.txt рядом): печатный лист блочного
конструктора документов. Выбран за полное покрытие кириллицы **и казахского
алфавита** (ә ғ қ ң ө ұ ү һ і) — без него приказ на казахском вышел бы квадратами.

Каталог монтируется в контейнер Gotenberg (`docker-compose.yml`, профиль `pdf`)
как системный каталог шрифтов Chromium. Те же файлы подключает веб (лист
конструктора) — превью и PDF набраны одним шрифтом.

Источник файлов: google/fonts → `ofl/ptserif` (upstream ParaType).
