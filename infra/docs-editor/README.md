# Редактор документов: своя сборка

Движок `core/docs` — WOPI-**хост**. Собственно редактор (WOPI-**клиент**) — внешняя
сменная деталь. Здесь собирается наш образ этой детали: из исходников Collabora Online
(MPL-2.0), обезличенный, с закреплёнными версиями.

Зачем не готовый `collabora/code`: их бинарники распространяются на дополнительных
проприетарных условиях, а исходники — чистый MPL-2.0. Подробности и обязанности —
[LICENSING.md](LICENSING.md). Товарные знаки Collabora из изменённой сборки убрать
**обязаны** — этим занят слой бренда.

## Что где

| | |
|---|---|
| `pins.env` | **единственный** источник правды о версиях: коммит исходников, ассет движка + его sha256, теги образов |
| `upstream/` | вендоренная обвязка Collabora, дословно, на закреплённом коммите (`UPSTREAM_SHA`) |
| `patches/` | наши правки к ней — отдельными `.patch`. Сейчас пусто, и это хорошо |
| `Dockerfile.builder` + `run-build.sh` | среда сборки и её логика |
| `Dockerfile.brand` + `brand/` | обезличивание и шрифты, отдельным дешёвым слоем |
| `build.ps1` | точка входа с Windows |
| `probe.ps1` | разведка: что именно надо обезличить |

## Два образа, а не один

| Образ | Содержимое | Пересборка |
|---|---|---|
| `superapp6/docs-editor-base:<версия>` | собранный из исходников coolwsd | долго, только при смене `ONLINE_COMMIT` |
| `superapp6/docs-editor:<версия>-b<N>` | `FROM base` + бренд + шрифты | **секунды**, при каждой правке оверлея |

Разделение существует потому, что список файлов брендинга находится опытным путём
(см. `probe.ps1`): если бы правка бренда требовала полной пересборки, разведка
превратилась бы в день многочасовых циклов. Побочно это делает дешёвым ежемесячное
обновление пакетов в brand-слое и превращает откат в смену тега.

## Сборка

```powershell
# оба слоя (первый раз — долго: качается ~440 МБ движка и компилируется online)
.\infra\docs-editor\build.ps1 -Stage all

# только бренд — сюда возвращаемся при каждой правке оверлея
.\infra\docs-editor\build.ps1 -Stage brand
```

При самом первом запуске сборка **намеренно остановится** и напечатает sha256
скачанного движка: его надо вписать в `pins.env` (`ENGINE_ASSETS_SHA256=`) и запустить
снова. Это не придирчивость — ассет перезаливают по тому же URL, и без закреплённой
суммы «пересборка без изменений» однажды тихо подменила бы версию LibreOffice.

## Подмена и проверка

```powershell
# 1. образ в docker-compose.yml (сервис docs-editor), затем:
docker compose --profile docs up -d

# 2. ОБЯЗАТЕЛЬНО после каждой пересборки — сбросить кэш discovery
.\infra\docs-editor\build.ps1 -Stage brand -FlushDiscovery

# 3. проверка
cd apps\api; node scripts\verify-docs.cjs      # ждём 64/0, а НЕ SKIP
```

**Про сброс кэша.** `DocsEditorClient` кэширует discovery в Redis на час, а в адресе
редактора зашит хэш сборки. Пропустить сброс — значит получить iframe, который час
стучится в 404, не оставляя ни одной ошибки на сервере. Это самая обидная и самая
частая ошибка при работе с этим образом.

## Обезличивание

```powershell
.\infra\docs-editor\probe.ps1 -CheckLicenses
```

Проходы A/B/D идут по образу, проход C — руками в браузере на живом редакторе
(заголовок вкладки, favicon, тулбар, «О программе», и главное — ноль запросов
на посторонние origin). Найденное записывается в `brand/manifest.md`, замены
кладутся в `brand/browser-dist/`.

Красная черта: `COPYING*`, `LICENSE*`, `licenses/`, `NOTICE` и копирайт-шапки
**не трогаем никогда** — MPL-2.0 §3.4. Диалог «О программе» теряет марку, но
сохраняет копирайт upstream.

## Обновление версии

1. `git ls-remote https://gerrit.collaboraoffice.com/online refs/heads/distro/collabora/co-26.04`
2. Новый sha → `ONLINE_COMMIT` и `BASE_TAG` в `pins.env`, `ENGINE_ASSETS_SHA256` очистить.
3. Перевендорить `upstream/` с того же коммита, обновить `UPSTREAM_SHA`, переналожить `patches/`.
4. `build.ps1 -Stage all` → вписать новую сумму ассета → снова.
5. Прогнать проверку целиком, включая браузер: после смены версии оверлей бренда
   может промахнуться мимо переехавших файлов.

Регламент: пин **на коммит**, никогда на имя ветки. Бренд-слой — ежемесячно,
base — ежеквартально или сразу на security-advisory Collabora.
